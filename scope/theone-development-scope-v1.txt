계약 첨부용 개발 범위 협의안 1.0 | 2026.10.23

사업자 고객이 여러 자재의 견적을 요청하거나 업체와 전문가에게 업무를 의뢰하면, 더원파트너스 운영 담당자가 접수 내용을 확인하고 직접 연락하는 플랫폼을 개발합니다. 실제 계약과 대금 수납은 사이트 밖에서 진행합니다.

01 개발 범위와 운영 원칙
사용자 홈페이지와 운영 관리자 화면을 한 서비스로 제공합니다. 아래 기본안은 계약 범위를 정하기 위한 제안이며, 합의한 문서 버전을 계약에 첨부합니다.

돈을 받는 일과 요청을 관리하는 일을 구분합니다

사이트에는 결제하기, 카드·간편결제, 결제대행 연동, 자동 환불·정산을 만들지 않습니다. 고객은 견적 요청과 의뢰만 제출합니다. 담당자는 별도 연락으로 조건과 비용을 협의하고, 거래 결과와 수납 여부를 관리자 화면에 수동으로 기록합니다.

사업자 회원 | 승인 후 회원 자재몰을 이용하고 견적·의뢰를 제출하며, 본인이 보낸 요청과 회신만 확인합니다.
운영 담당자 | 접수 자료를 검토하고 고객·공급사·전문가에게 연락하며 견적서와 상담 진행 내용을 등록합니다.
최고 관리자 | 직원 권한, 회원 승인·등급, 공개 콘텐츠와 전체 업무 현황을 관리합니다.

기본 운영 가정은 사업자 회원 수동 승인, 회원 1계정당 1담당자, 전문가·업체의 운영사 직접 관리입니다. 기업 내 여러 직원의 자료 공유와 전문가 자체 업무 처리는 별도 협의합니다.

권한은 화면 메뉴와 실제 자료 조회·수정 모두에 적용합니다. 내부 메모, 공급가, 수납 기록, 다른 고객의 요청은 사용자 화면에 표시하지 않습니다. 삭제 대신 비공개·이용 정지·취소를 기본으로 사용해 처리 이력을 남깁니다.

04 요청부터 상담 종료까지
견적요청서는 고객이 제출한 요구 목록이고, 견적서는 운영사가 검토 후 등록하는 가격·납기 자료입니다. 요청 접수만으로 주문·계약·결제가 확정되지 않습니다.

자재 견적
고객: 여러 자재·규격·수량 담기 → 고객: 현장·납기 입력 후 한 번에 요청 → 운영 담당자: 요청서 확인·공급 조건 상담 → 운영 담당자: 회신 견적서 파일 등록 → 고객과 담당자: 별도 연락·계약·수납 후 결과 기록

업체와 전문가 의뢰
고객: 업체·전문가 선택 또는 미지정 → 고객: 현장·업무·희망 일정 제출 → 운영 담당자: 고객 요구·후보 가능 여부 확인 → 운영 담당자: 연결 결과와 상담 내용 등록 → 고객과 담당자: 별도 연락·계약·수납 후 결과 기록

진행 상태 | 뜻과 다음 처리
접수 | 제출 즉시 접수번호를 만들고 고객·관리자 목록에 표시합니다.
검토 중 | 담당자가 자료를 검토하고 부족한 정보나 조건을 확인합니다.
견적 안내 또는 연결 협의 | 자재는 견적서 등록 후 안내합니다. 의뢰는 후보 연락과 연결 협의를 진행합니다.
상담 중 | 최종 조건·금액·일정을 사이트 밖에서 협의합니다.
종료 | 성사·미성사 구분, 종료일과 사유를 기록합니다. 종료가 결제 완료를 뜻하지 않습니다.
보류·취소 | 단계 중간에도 사유를 남겨 전환할 수 있습니다. 재개는 담당자가 이력을 남겨 처리합니다.

고객에게는 현재 단계, 공개 회신, 견적서, 담당 문의처를 보여 줍니다. 후보와 협의한 내부 내용·원가·수납 상세는 공개하지 않습니다. 고객 취소는 접수 단계에서 직접 처리하고, 검토 이후에는 취소 요청을 남겨 담당자가 확정합니다.

05 자재 견적에 필요한 정보
여러 품목을 하나의 접수번호로 묶습니다. 장바구니의 역할은 구매가 아니라 견적 담기이며, 확정 금액은 운영사가 작성한 회신 견적서로 안내합니다.

입력 영역 | 항목과 처리 기준
품목별 필수 정보 | 자재, 규격·옵션, 거래 단위, 수량. 동일 자재·동일 규격은 수량을 합치고, 규격이 다르면 별도 줄로 관리합니다.
가격 표시 | 단가가 등록된 품목은 회원 등급별 참고 단가와 예상 금액을 표시합니다. 단가 미정 품목은 ‘견적 문의’로 표시하고 0원으로 오해하게 만들지 않습니다.
요청자 필수 정보 | 회사명, 담당자명, 연락처, 이메일. 회원정보를 불러오되 해당 요청의 연락처를 별도로 확인할 수 있습니다.
현장 필수 정보 | 현장명, 납품 지역·주소, 희망 납기 또는 ‘일정 협의’. 상세 반입 조건·하차 조건은 메모로 받습니다.
추가 정보 | 요청사항과 도면·사진·품목표 첨부. 첨부는 선택이며 필수 입력 누락을 먼저 안내합니다.
제출과 보관 | 제출 직전 품목·규격·수량·연락처를 확인합니다. 접수번호와 접수 시각을 생성하고 당시 품목·단가·등급 정보를 보관합니다.

견적서 회신 기본안

운영 담당자가 기존에 사용하는 양식으로 견적서를 작성하고 PDF 파일을 등록합니다. 사이트는 등록 파일의 열람·내려받기, 안내문, 견적일·유효기간, 수정 이력을 제공합니다. 품목별 단가·세금·운임을 사이트 안에서 작성하고 견적서를 자동 생성하는 기능은 별도 협의합니다.

회신 항목 | 관리 방식
필수 | 회신 제목, 견적서 PDF, 작성일, 유효기간 또는 별도 협의 표시, 고객용 안내문
조건 안내 | 세금 포함 여부, 운임·하차비, 납기와 유효 조건을 견적서와 회신 안내에서 확인할 수 있도록 등록합니다.
수정본 | 재등록 시 새 버전과 변경 사유를 남깁니다. 고객에게 최신본을 먼저 보여 주고 이전본은 이전 버전으로 구분합니다.
내부 기록 | 공급사, 담당자, 협의 메모와 최종 협의금액을 별도로 기록합니다. 내부 기록은 고객에게 노출하지 않습니다.

접수 후 자재 가격이나 회원등급이 바뀌어도 이미 접수된 요청서는 바뀌지 않습니다. 품목 변경은 변경 요청과 재견적 이력을 남깁니다. 금액이 없는 품목이 섞이면 합계를 확정 총액으로 표시하지 않습니다.

06 업체와 전문가 의뢰 정보
고객이 전문가를 지정해도 요청은 운영사에 먼저 접수됩니다. 지정한 전문가에게 자동 발송하거나 즉시 계약을 체결하는 구조는 기본안에 포함하지 않습니다.

입력 영역 | 항목과 처리 기준
희망 대상 | 업체 또는 전문가를 지정하거나 ‘담당자 추천’을 선택합니다. 선택한 대상의 이름과 식별정보를 요청에 함께 남깁니다.
업무 필수 정보 | 필요 분야·공종, 현장명, 현장 지역·주소, 의뢰 내용, 희망 일정 또는 ‘일정 협의’
요청자 필수 정보 | 회사명, 담당자명, 연락처, 이메일. 수집·이용 안내 확인 후 제출합니다.
추가 정보 | 공사 규모·면적, 예상 예산 또는 협의 여부, 자격 조건, 도면·현장 사진 첨부
처리 정보 | 담당자, 연락한 후보, 연락일, 응답·가능 일정, 연결 여부, 고객에게 안내한 내용, 다음 연락 예정일

업체와 전문가 등록

제휴 신청에서 업체 유형, 회사·전문가명, 담당 연락처, 분야·지역, 소개, 자격·면허, 대표 실적, 검토용 증빙을 받습니다. 운영 담당자가 확인한 뒤 승인·반려하고, 승인된 공개 정보만 목록에 노출합니다. 등록 당사자가 의뢰를 직접 받거나 견적을 회신하는 전용 관리 화면은 기본 범위에서 제외합니다.

사업자·자격 확인은 운영 담당자가 제출 자료를 확인하는 방식입니다. 사업자 진위·자격·면허를 외부 기관과 자동 대조하거나 확인 결과를 보증하는 기능은 포함하지 않습니다.
